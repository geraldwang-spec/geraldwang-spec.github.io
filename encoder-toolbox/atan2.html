atan2 做了什麼

數學上 tan φ = s ÷ c，所以 atan(s ÷ c) 看起來就能算出角度。但 atan 只能傳回 −90° ~ +90°，只看比例，看不到 s 和 c 各自的正負號。atan2 把 s、c 分開傳進去，先算 atan，再依照 c 的正負號決定要不要補 180°：

c > 0　　　　　→ atan2 = atan(s ÷ c)
c < 0，s ≥ 0　→ atan2 = atan(s ÷ c) + 180°
c < 0，s < 0　→ atan2 = atan(s ÷ c) − 180°
c = 0，s > 0　→ atan2 = +90°　（不做除法，所以不會除以零）
c = 0，s < 0　→ atan2 = −90°
結果範圍 −180° ~ +180°；編碼器要 0° ~ 360°，負的再加 360°
點scs ÷ catan(s ÷ c)atan2(s, c)0 ~ 360°

前兩列的 s ÷ c 完全一樣，atan 只能給出同一個答案，但兩個點在圓的兩側，差了 180°。

在編碼器裡怎麼用

一定要 sin 和 cos 都有

只有 sin 時，0.5 可能是 30° 也可能是 150°。有了 cos 的正負號，atan2 才能分辨點在哪個象限，每個角度只對應一組 (s, c)。

振幅不影響角度

把半徑拉小，點的方向不變，atan2 的結果也不變，因為它只看方向。所以氣隙變大時角度還算得出來，但要靠 √(s² + c²) 的振幅檢查發現訊號變弱。

單位是弧度

程式裡的 atan2 傳回弧度，要乘上 180 ÷ π ≈ 57.2958 才是度數。參數順序是 atan2(y, x)，先放 s 再放 c，放反了角度會錯。

晶片裡用 CORDIC

編碼器晶片通常不用浮點數算 atan2，而是用 CORDIC：把向量一步步往 0° 轉，每步轉的角度越來越小，只需要加減和移位，再把轉過的角度加總。

// s、c 是正規化後的 sin、cos（−1 ~ +1）
float phi = atan2f(s, c) * 57.29578f;   // 弧度 → 度，範圍 −180 ~ 180
if (phi < 0.0f) phi += 360.0f;          // 轉成 0 ~ 360°

float amp = sqrtf(s * s + c * c);       // 振幅檢查，正常約 1.0
if (amp < 0.7f || amp > 1.3f) fault(ENC_SIGNAL);
