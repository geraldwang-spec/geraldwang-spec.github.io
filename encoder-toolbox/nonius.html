Nonius 絕對角度計算

兩條極數差 1 的磁軌，各自只知道「在一對極裡的位置」。把兩者相減就知道整圈的絕對角度，再交給極數多的主軌算出精確值。下面的試算從 ADC 原始讀值開始，照 MCU 的流程一路算到角度。

電氣相位 vs. 機械角

計算方式

設主軌有 M 對極、Nonius 軌有 M − 1 對極。磁環轉一圈（360° 機械角），主軌的相位轉 M 圈，Nonius 軌轉 M − 1 圈。讀頭只看得到「目前在一對極裡的位置」，也就是取 mod 360 後的電氣角。

φA = M·θ mod 360
φB = (M−1)·θ mod 360
d  = (φA − φB) mod 360   → 數值上等於 θ（粗）
k  = round( (M·d − φA) / 360 ) mod M
θ  = (φA + 360·k) / M

為什麼相減會得到 θ

M·θ − (M−1)·θ = θ。兩軌每圈只差一個週期，所以差值在整圈內只出現一次，每個角度都有唯一的值。

k 在算什麼

如果粗角度 d 是準的，M·d 就是主軌「沒被 mod 掉」的總相位。減掉讀到的 φA 再除以 360，剩下的整數就是主軌已經走過幾個完整週期。

為什麼最後用 φA

d 是兩軌相減，誤差疊加，精度較差。k 只取整數，對誤差有容忍度；真正的精度由 φA 決定，而且主軌誤差會被除以 M。

範例：32 / 31

每列都用上面的公式算（不含 ADC 誤差）。主軌一個週期是 360 / 32 = 11.25°，k 就是 θ 落在第幾格。

情況θ 實際φA = 32θ mod 360φB = 31θ mod 360d（粗）kθ 輸出

以 θ = 100° 手算：φA = 3200 mod 360 = 320°，φB = 3100 mod 360 = 220°，d = 100°，k = round((3200 − 320) / 360) = 8，θ = (320 + 2880) / 32 = 100°。

誤差容許與判錯

只要 k 算對，輸出精度只看主軌。但如果粗角度 d 的誤差讓 M·d 偏差超過半個週期（180° 電氣角），round 就會取到隔壁的整數，輸出會整格跳掉 360 / M 度。

為什麼極數差一定是 1

如果用 32 / 30，相位差變成 2θ，一圈內會重複兩次。θ = 50° 和 θ = 230° 的兩軌讀值完全相同，系統分不出是上半圈還是下半圈。

32 / 30φA = 32θ mod 360φB = 30θ mod 360φA − φB

MCU 如何經由 ADC 讀出位置

讀頭給 MCU 的不是角度，而是類比電壓。每條磁軌下有兩組感測器，彼此錯開 1/4 對極（90° 電氣角），一組輸出 sin(φ)、一組輸出 cos(φ)。兩條磁軌共 4 路訊號，就是互動試算第 1 步的 4 個通道。

感測

sin / cos 電壓

每軌兩組霍爾或 TMR，常用差動輸出消除共模雜訊。

取樣

4 路 ADC

sin 與 cos 必須同時取樣，觸發和 PWM 同步。

校正

偏移、增益、相位

出廠轉一圈量測參數，存在 Flash。

解相位

atan2(s, c)

得到 −180°~180°，再 mod 360 轉成 φ。

Nonius

φA、φB → θ

扣除兩軌安裝偏移後算 d、k、θ。

檢查

確認可信

振幅、k 的餘裕、角度連續性，任何一項異常就報錯。

韌體範例（C）

// 每條磁軌的出廠校正參數
typedef struct { float off_s, off_c, amp_s, amp_c, ph; } cal_t;

static float wrap(float x){ x = fmodf(x, 360.0f); return x < 0 ? x + 360.0f : x; }

// 原始 ADC 值 → 校正 → atan2 → 電氣相位 0~360°
float track_phase(uint16_t raw_s, uint16_t raw_c, const cal_t *k, float *amp)
{
    float s = (raw_s - k->off_s) / k->amp_s;      // 去偏移、正規化振幅
    float c = (raw_c - k->off_c) / k->amp_c;
    s = (s - c * sinf(k->ph)) / cosf(k->ph);      // 修正 sin/cos 不是剛好差 90°
    *amp = sqrtf(s * s + c * c);                  // 理想值 1.0
    return wrap(atan2f(s, c) * 57.29578f);
}

// 兩軌相位 → 絕對角度；回傳 0 表示 k 有足夠餘裕
int nonius(float phiA, float phiB, int M, float *theta)
{
    phiB = wrap(phiB - TRACK_OFFSET);             // 出廠量測的兩軌安裝偏移
    float d   = wrap(phiA - phiB);                // 粗角度
    float raw = (M * d - phiA) / 360.0f;          // 理想上接近整數
    int   k   = ((int)lroundf(raw) % M + M) % M;
    float res = raw - lroundf(raw);               // 離最近整數多遠
    *theta = (phiA + 360.0f * k) / M;
    return fabsf(res) < 0.25f ? 0 : -1;           // 超過 1/4 格就警告
}

// 由 PWM 同步觸發，4 個通道同時取樣完成後進入
void ADC_IRQHandler(void)
{
    float ampA, ampB, theta;
    float phiA = track_phase(adc[0], adc[1], &calA, &ampA);
    float phiB = track_phase(adc[2], adc[3], &calB, &ampB);

    if (ampA < 0.7f || ampA > 1.3f || ampB < 0.7f || ampB > 1.3f) { fault(ENC_SIGNAL); return; }  // 氣隙或外部磁場
    if (nonius(phiA, phiB, 32, &theta) != 0)                          { fault(ENC_NONIUS); return; }  // k 快判錯
    if (fabsf(wrap(theta - last + 180.0f) - 180.0f) > MAX_STEP)       { fault(ENC_JUMP);   return; }  // 不可能的跳動
    last = theta;
}

為什麼要 sin 和 cos

只有 sin 時，0.5 可能是 30° 也可能是 150°。加上 cos 後，每個相位只有一組 (sin, cos)，atan2 才能分辨四個象限與旋轉方向。

為什麼要同時取樣

先讀 sin、隔 2 µs 再讀 cos，磁環已經轉了。關節馬達端 3000 rpm、32 對極時，2 µs 的電氣角變化約 1.15°，會直接變成角度誤差。

校正參數怎麼來

出廠時慢速轉一圈，記錄每個通道的最大、最小值：偏移 = (最大 + 最小) / 2，振幅 = (最大 − 最小) / 2；相位誤差用李薩如橢圓擬合求出。

解析度

12 位元 ADC 經 atan2 後，每個極週期約可分 10~12 位元。主軌 32 週期再多 5 位元，整圈約 15~17 位元。

商用關節多用 iC-MU 這類專用晶片，類比前端、校正、atan2 與 Nonius 計算都在晶片內完成，MCU 只透過 SPI 或 BiSS 讀一個角度值。用線性霍爾或 TMR 直接接 MCU 的 ADC 成本較低，但校正與抗干擾都要自己處理。

韌體實作要注意

  • 所有相減都要做環繞處理：((x % 360) + 360) % 360。在 0° 附近，d 會在 359.9° 和 0.1° 之間跳，數學上是連續的。
  • k 取整後也要 mod M，避免 θ 接近 360° 時算出 k = M。
  • 先做兩軌的偏移、振幅、相位校正，再做 Nonius 計算。兩軌的機械安裝偏移（track offset）也要在出廠時量測並扣掉。
  • 加一個一致性檢查：算出的 θ 用 (M−1)θ 反推 φB，和實際讀值差太多就報錯。
  • 偏心會讓兩軌產生不同的一次諧波誤差，是 k 判錯最常見的原因。64/63 對同心度的要求是 32/31 的兩倍。
